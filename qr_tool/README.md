# 批量二维码生成工具（Python 版）

与 VB.NET 版本功能一致的桌面工具，用于批量生成二维码图片。

## 环境要求

- Python 3.8+
- 依赖库：`qrcode`、`pillow`

## 安装依赖

```bash
cd qr_tool
pip install -r requirements.txt
```

## 运行

```bash
python main.py
```

## 功能说明

1. 在上方文本框每行输入一个二维码内容
2. 在下方文本框输入对应文件名（可选，不填则使用默认名称 `code1.jpg`、`code2.jpg` ...）
3. 选择保存路径（不选则默认保存到桌面 `QR_Codes` 文件夹）
4. 点击"生成二维码"按钮，批量生成 JPG 格式二维码
5. 支持从原始文档导入：点击"选择原始文件"选择 txt 文档，每行格式为：
   ```
   需要生成二维码的内容丨二维码图片名称
   ```
   选择后按钮变为"生成二维码内容与名称"，点击即可自动填充到文本框
6. 生成完成后可选择是否打开保存目录
